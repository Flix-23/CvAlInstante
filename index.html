💡 Professional CV Generator API

Descripción

Professional CV Generator API es una API RESTful desarrollada en ASP.NET Core 8 que permite crear, personalizar y generar currículums profesionales de manera dinámica y automatizada. El sistema facilita a los usuarios registrar su información personal, experiencia laboral, educación y habilidades, generando un CV profesional en formato PDF a partir de plantillas predefinidas y personalizables.

Esta API está diseñada para integrarse con aplicaciones web o móviles que requieran funcionalidades de generación de CV, portafolios o perfiles profesionales.

⚙️ Funcionalidades principales

  • Registro y gestión de información personal, experiencia y formación.
  • Generación de currículums en formato PDF con plantillas dinámicas.
  • Integración con aplicaciones web o móviles mediante endpoints RESTful.
  • Validaciones de datos y estructura adaptable a distintos perfiles.

🧩 Tecnologías utilizadas

  • ASP.NET Core 8 (C#)
  • Entity Framework Core
  • SQL Server / PostgreSQL
  • AutoMapper
  • iText7 o QuestPDF (para generación de PDF)
  • Swagger (documentación de API)

🎯 Objetivo

Brindar una solución moderna y escalable para la generación automatizada de currículums profesionales, facilitando la integración con plataformas educativas, portales de empleo o sistemas de gestión de talento.
