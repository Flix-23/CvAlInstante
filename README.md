💡 Descripción

Professional CV Generator API es una API RESTful desarrollada en ASP.NET Core 8 que permite crear, personalizar y generar currículums profesionales de manera dinámica y automatizada.
El sistema facilita a los usuarios registrar su información personal, experiencia laboral, educación y habilidades, generando un CV profesional en formato PDF a partir de plantillas predefinidas y personalizables.

Esta API está diseñada para integrarse con aplicaciones web o móviles que requieran funcionalidades de generación de CV, portafolios o perfiles profesionales.
